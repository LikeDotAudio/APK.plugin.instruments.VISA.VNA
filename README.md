# INSTRUMENT.VNA

**Wiki:** [Documentation/README.md](Documentation/README.md) — principles, architecture, delivery, and the [SDK](Documentation/%F0%9F%A7%A9Manual%20and%20Artifacts/SDK.md).

The **VNA** instruments of the APK.audio bench, as one thing: 8 models, their command tables and the family's panel. Vector network analysers: stimulus, response and the trace.

| | |
|---|---|
| **Is** | **source** — puts something out — a stimulus, a supply or a load<br>**inputs** — takes signals in — its connectors are inputs a patch can land on<br>**metering** — measures — its readings are numbers with units<br>**monitoring** — shows — a trace, a waveform or a display you watch |
| **Inputs** | each model's BIM part: /api/bim/parts?full=1&id=<part> — ports where side is "input" and domain is not "power" |
| **Recipe** | none — data, not a container: read in place by the stacks that bake `INSTRUMENTS` |
| **Source** | this repository (https://github.com/LikeDotAudio/APK.plugin.instruments.VISA.VNA.git), a submodule of [APK.plugin.instruments.VISA](https://github.com/LikeDotAudio/APK.plugin.instruments.VISA) at `INSTRUMENT.VNA/` |
| **Family name** | `VNA` — the device type, the topic segment and the `manifest.json` key; the `INSTRUMENT.` prefix belongs to the folder only |

## Layout

```
INSTRUMENT.VNA/
  thing.json            what this thing is on the bench (authored)
  gui/                  the family panel, stamped once per discovered box
    VNA.json
  <Model>/              <Model>.komand (the command table), <Model>.gui,
                        <Model>.api.json (generated), commands_tree.md, SOURCES.md
  Documentation/        the wiki; SDK/ is generated by _komand/family_sdk_docs.py
```

Generated by `_komand/family_sdk_docs.py` in the parent repository; edit `thing.json` or the
models, not this page.
